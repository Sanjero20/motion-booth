# Motion Booth

A web-based photobooth that captures not only photos, but also the moments leading up to each shot.

## Features

- **Photo templates** — Classic Strip, Grid, and Story.
- **Timed capture** — Four shots with a countdown for each.
- **Motion capture** — Records the five seconds before each shot.
- **Photo and video export** — Download the finished photo or an 8-second motion video.
- **QR sharing** — Generate a QR code for sharing session results.

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Animations:** Framer Motion
- **Backend (planned):** ASP.NET Core Web API
- **Database (planned):** PostgreSQL
- **Cloud (planned):** Microsoft Azure

## Getting Started

```bash
npm install
npm run dev
```
